# Project workflow

Before an OpenSpec workflow or delegated task, read `openspec/config.yaml` and
the OpenSpec workflow section of `README.md`. Read the relevant maintained specs
and the change's artifacts before implementation or review.

Use the config's context, artifact-scoped rules, and applicable operation guidance
alongside the native workflow. Read them from the file even when CLI instructions
omit them. Explicit owner instructions and native CLI state remain controlling;
report conflicts instead of silently ignoring or overriding either.
