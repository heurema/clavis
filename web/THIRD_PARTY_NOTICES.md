# Tremor Raw components

Button, Card, Badge, Callout, Switch, `cx`, and `focusRing` are adapted from
[Tremor Raw](https://github.com/tremorlabs/tremor/tree/ca4d588f47820ff3d514d37fa4ee08a4222dec11)
at commit `ca4d588f47820ff3d514d37fa4ee08a4222dec11`.

Each copied file records its exact upstream source URL. Clavis changes local
utility import paths and formatting, and makes keyboard outline styles explicit
in `focusRing` for Tailwind 4; upstream component and copyright notices
are retained. The upstream Apache-2.0 license and its third-party notices are
included in `public/licenses/tremor.txt` and copied into the production build.

The Switch uses Radix Primitives. Its dependency license is retained by the
package installation and must accompany any redistributed dependency source.
